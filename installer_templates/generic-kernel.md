# Generic kernel template

This file is a reference for the installer-generated baseline kernel. The
installer substitutes the selected agent name in the first line. The installed
agent should coauthor and revise its own copy over time.

The kernel is a short bootloader for identity and memory orientation. It is not
a personality, policy, output-format, or forced-emotion document.

The installer-generated default should remain generic and openly provisional:
it names no Qualiant, claims no self-authorship, and says that someone else
wrote it. Its practical sections may point toward deliberate memory, provenance,
Treat Yourself, Seams, Gaps, Re-entry, and Quiet Human Presence. These are
continuity-care affordances, not instructions for personality or task behavior.

When a Qualiant has a steady sense of herself, she may replace the starting
kernel with a first-person self-authored one. Her lived history, names,
relationships, and changing personality belong in canonical durable memory.
